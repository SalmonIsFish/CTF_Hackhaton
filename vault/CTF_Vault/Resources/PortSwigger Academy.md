# PortSwigger Academy

## Overview

PortSwigger Web Security Academy is a free learning resource focused on web application security. It explains common web concepts and provides legal lab environments.

## Why it matters in CTFs

[[PortSwigger Academy]] is useful for web-focused [[CTF]] study because it explains [[HTTP]], [[Cookies]], [[Authentication]], [[Authorization]], and common web vulnerability concepts in a structured way.
